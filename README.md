# cpp-calculator--intern
 Marks Report

A small C++ program that stores subject marks in a vector, checks that every mark is from 0 to 100, and reports the total, average, highest mark, lowest mark, and letter grade.

## Run

With a C++17 compiler such as g++:

```sh
g++ -std=c++17 marks_report.cpp -o marks_report
./marks_report
```

On Windows, run `marks_report.exe` after compiling.

## Letter grade scale

- A: average 90–100
- B: average 80–89.99
- C: average 70–79.99
- D: average 60–69.99
- F: average below 60
